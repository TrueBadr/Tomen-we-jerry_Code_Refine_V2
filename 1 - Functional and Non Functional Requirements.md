# A - Functional Requirements 
* Candidates and employers can create profiles
* Candidates and employers can add and update their skills, expertise, experience, and other profile information
* Employers can define job listings with required skills, experience level, salary range, eligibility criteria, and other relevant information
* Candidates can search and filter job listings by skills, expertise, experience level, and other criteria
* The system can recommend candidates to employers based on skills, expertise, and experience level
* Candidates can apply for jobs
* Employers can search and filter candidates by skills, expertise, experience level, and other criteria
* The system analyzes the skill gap between a candidate's profile and a target job based on required skills and experience
* Employers can review applications
* The system can recommend jobs to candidates based on skills, expertise, and experience level
* Employers can move candidates through the application pipeline
* The system sends notifications for relevant events
# B - Non-Functional Requirements
* Performance
* Availability
* Reliability
* Scalability
* Consistency : The system must maintain data consistency and prevent duplicate or conflicting applications.
* Security and Privacy
* Usability
* Observability
* Maintainability
